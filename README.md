# Cómo funciona un banco

La cadena de valor de un banco contada para cualquier área: captación, crédito, cobranza, pagos y tarjetas, canales digitales, core bancario, contabilidad bancaria, open banking, fraude, prevención de lavado y la regulación vista desde la operación.

**Ver en línea:** https://aaramirez.github.io/banca/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
